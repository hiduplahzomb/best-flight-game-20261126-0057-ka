Fly as Capt. Maren Lind (callsign Fulmar-4) in the twin-prop STOL amphibian KV-14 "Fulmar" across the sub-arctic volcanic archipelago of Skarv Sound. Five evacuation sorties thread a basalt sea arch, geothermal ridges and a glacier before a pyroclastic storm front closes the fjord: fly beacon rings, ride thermal updrafts, fight lee-rotor shear, manage flaps, gear, de-ice and fuel, then put the Fulmar down on short flare-lit cliff strips in crosswind. A live V-SCOPE vertical situation display plots terrain, arch clearance, wind shear and a parabolic landing arc; every landing is graded and recorded by a black-box flight recorder.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in Chrome. Keyboard only: arrows/WASD pitch and roll, Q/E rudder, Shift/Ctrl throttle, F flaps, G gear, I de-ice, B brake/reverse, C camera, P pause, X refly, M mute.
